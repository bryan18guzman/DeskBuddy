# DeskBuddy

A Raspberry Pi-powered animated desk companion inspired by products like the Dasai Mochi, built from scratch in Python.

## Features
- Animated facial expressions
- Mood engine
- Touch interaction

## Hardware
- Raspberry Pi 3 Model B
- Waveshare GC9A01 Round LCD
- Capacitive touch sensor
